# Credits

## Packages Used

This project is built on top of amazing open-source packages. We're grateful to their authors and maintainers.

### Core Framework
- [Laravel](https://laravel.com) - The PHP framework for web artisans
- [Filament](https://filamentphp.com) - The elegant TALL stack admin panel for Laravel
- [Livewire](https://livewire.laravel.com) - Full-stack framework for Laravel that allows building dynamic interfaces

### Page Builder
- [z3d0x/filament-fabricator](https://github.com/z3d0x/filament-fabricator) - Page builder framework for Filament

### Filament Plugins
- [mokhosh/filament-rating](https://github.com/mokhosh/filament-rating) - Rating component for Filament
- [guava/filament-icon-picker](https://github.com/guava-labs/filament-icon-picker) - Icon picker for Filament forms

### Icon Libraries
- [codeat3/blade-unicons](https://github.com/codeat3/blade-unicons) - Unicons for Laravel Blade
- [codeat3/blade-google-material-design-icons](https://github.com/codeat3/blade-google-material-design-icons) - Google Material Design Icons for Laravel Blade
- [codeat3/blade-devicons](https://github.com/codeat3/blade-devicons) - Devicons for Laravel Blade
- [blade-ui-kit/blade-icons](https://github.com/blade-ui-kit/blade-icons) - A huge collection of SVG icons as Blade components
- [blade-ui-kit/blade-heroicons](https://github.com/blade-ui-kit/blade-heroicons) - Heroicons for Laravel Blade

### Development Tools
- [Pest](https://pestphp.com) - Elegant testing framework for PHP
- [Laravel Pint](https://github.com/laravel/pint) - Automatic PHP code style fixer for Laravel
